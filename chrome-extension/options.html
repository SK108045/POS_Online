KRA portal field mapping

Default mappings use field names and labels. After live KRA testing, override only selectors that differ. Values are CSS selectors. The extension never fills the customer name or selects a tax category.

Supported keys: pin, phone, email, billing_address, reference, payment_method, discount_type, discount_value, rows, add_item, item_name, item_description, item_quantity, item_price, total, seller_pin, generate, cu_invoice_number, scu_id, receipt_signature, invoice_number, invoice_date, invoice_root, qr.
